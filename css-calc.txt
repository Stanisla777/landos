Тема: [Заявка] Установка Node Version Manager (NVM) и Node.js v20 (с обязательным сохранением текущей v18) для работы над проектами

Добрый день!
Для выполнения рабочих задач по frontend-разработке мне требуется возможность переключаться между разными версиями Node.js, так как наши проекты имеют строгие требования к окружению:
Текущие рабочие проекты требуют Node.js v18.x (которая уже установлена в системе).
Новые/обновляемые проекты (с использованием современных сборщиков, таких как Rspack/Vue 3) требуют Node.js v20.x.
В связи с этим прошу выполнить следующую установку:
Установить Node Version Manager for Windows (NVM). Это стандартный инструмент, который позволяет безопасно хранить и переключать несколько версий Node.js на одном компьютере без конфликтов.
Ссылка на официальный релиз: https://github.com/coreybutler/nvm-windows/releases (файл nvm-setup.exe)
С помощью NVM установить Node.js v20.x.x (актуальная LTS-версия, например, 20.11.0 или новее).
ВАЖНО: Пожалуйста, НЕ удаляйте и НЕ перезаписывайте текущую установленную версию Node.js v18. Она критически важна для стабильной работы текущих проектов. NVM позволяет управлять обеими версиями параллельно.
