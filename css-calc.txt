Максимальное значение = значению Максимальной суммы вычета за проценты по ипотеке на год, указанный в поле "Год регистрации права собственности".

Максимальная сумма вычета за проценты по ипотеке - значение должно устанавливаться в админке, должна быть возможность внести разные значения для разных лет регистрации объекта. Для периода с 2014 и позднее необходимо указать Максимальную сумму вычета за проценты по ипотеке = 3 000 000. При изменении законодательства должна быть возможность указать окончание периода для суммы 3 000 000 (например, 2027 год) и дополнительно внести еще одну сумму для следующего периода (например, с 2028 года и позднее). Фронт должен запрашивать с бэка Максимальную сумма вычета за проценты по ипотеке на год, указанный в поле "Год регистрации права собственности".
