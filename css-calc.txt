Уточняю информацию по запрошенному ПО:
1.  Node.js: версия 22.19.0 (как указано в первоначальной заявке)
2 NVM (Node Version Manager): 
Ссылка на дистрибутив (файл nvm-setup.exe): github.com/coreybutler/nvm-windows/releases/download/1.1.12/nvm-setup

прошу установить последнюю стабильную версию ветки v1.1.12 (или актуальную v1.x.x)

Касательно установки Node.js v22.19.0:
Прошу вас установить эту версию через консольную команду NVM (командой nvm install 22.19.0).
Я опасаюсь, что из-за политики безопасности в Citrix у меня не будет прав администратора для самостоятельного выполнения этой команды.
Просто если использовать стандартный .msi установщик Node.js с официального сайта – это приведёт к перезаписи установленной версии Node.js v18.20.4 и сломает проекты.
